# Auto Paint Lab — Logo Update

This package updates the existing Auto Paint Lab logo without redesigning it.

Changes:
- Logo artwork retained from the original project.
- Logo image assets enlarged to 2× their original pixel dimensions and lightly sharpened.
- React site header now uses the transparent logo mark and renders it larger.
- React footer uses the full logo at a larger size.
- Static HTML headers use the same higher-resolution logo mark and larger display dimensions.

## GitHub implementation
Copy the files/folders in this package into the root of the repository, replacing files with the same paths. Commit and push.

The important files are `SiteHeader.tsx`, `SiteFooter.tsx`, `mobile-paint.tsx`, all updated static `.html` pages, and the files under `assets/images/`.
